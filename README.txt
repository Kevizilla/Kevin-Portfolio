KEVIN STEPHEN — PORTFOLIO

Files
- index.html : page structure and content
- styles.css : all styling and responsive layout

How to run
1. Keep index.html and styles.css in the same folder.
2. Double-click index.html, or open the folder in VS Code and use Live Server.

Before submission
- Replace the placeholder email in index.html.
- Replace the CSS avatar in .hero-photo with your own image when you have one.
- Update project descriptions/links with your real links.

The site intentionally uses only HTML + CSS and avoids JavaScript so the implementation is easier to understand for a viva.
